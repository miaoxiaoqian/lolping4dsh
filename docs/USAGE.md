# DSH 快捷求助

快捷问答复用 DSH 正式会话，默认工作区为 `~/Documents/DSH快捷求助`，Markdown 记录位于其中的 `对话记录`。

轮盘默认按住 Ctrl 并移动鼠标选择，松开确认。普通空格、Ctrl 组合与拖选应正常放行。原版图片、动画与音效的来源见 `assets/ATTRIBUTION.md`。

“弱爆”等反馈默认针对当前小窗最近完成的正式回答，重启后从同一会话恢复。新问题不会继续评价旧会话。明确选择桌面端回答时，使用该回答的“对这条使用轮盘”；这项选择不会被小窗默认值覆盖。

构建：`npm run build`。检查：`npm run typecheck` 与 `npm run selftest`。这些检查不能代替当前安装版本的真实桌面和模型验收。

“需要视野”进入 macOS 框选截图，完成后在小窗预览；只有点击发送才经 DSH 附件服务上传。可以选择 PNG 图片，移除附件或取消框选。图片属于明确的会话，切换会话不允许误发；模型明确不支持图片时保留截图并提示更换模型。

小窗设置可指定 Markdown 记录文件夹（包括 Obsidian 库内目录）；后续记录和附件写入新位置，旧文件保留原位，正式 DSH 会话仍属于专用工作区。“超赞”写入正式会话反馈且不调用模型，“正在路上”只恢复被停止的任务。

轮盘动作动画由独立透明窗口播放，原版信号扩散效果改编自 lolPing；反馈层不接收鼠标点击，聊天页不再绘制覆盖输入框的表情。小窗标题栏根据真实鼠标位移拖动并保存位置。

构建与隔离检查通过不代表安装版已完成验收；实际桌面、录屏权限及真实模型输入仍需逐项验证。

轮盘反馈使用独立的 `quick-help-feedback` 来源和 `notice` 展示形式，小窗只展示简短反馈状态；正式聊天可展开查看内部指令。每个动作携带确切回答 ID，指令不重复粘贴历史答案和需求。“弱爆”先写入官方负面回答反馈，再在原会话执行一轮改进；模型输入完整保留在正式会话日志，用户尚未发送的草稿不受影响。

聊天界面不显示保存路径横条，目录仍可在设置中查看和更改。动作反馈贴近小窗侧边，视觉边缘间隔约 12 像素；四个表情动画均为 112px，四个信号均为 64px。

小窗使用独立的紧凑呈现：隐藏主窗标题、视图标签、统计栏和宠物，模型、权限和截图位于更多菜单。底层仍使用正式工具、附件、审批和会话。轮盘测试提供 15 秒可点击图标的交互；每次选择先播放原版反馈，动作的拒绝、空闲或排队通过简短状态说明，不把动画当成完成证明。


小窗标题栏提供新建与原生会话选择框，仅列出本插件在 DSH快捷求助 工作区创建的会话。打开目标前先恢复正式会话，成功后清除旧轮盘目标；拒绝过期小窗和无关会话 ID。新问题保留各会话原有草稿。轮盘新增 24/32px 缩放档，默认 32px 时整张透明轮盘为 400 DIP，原版图标、方向与独立表情动画不变。

反馈面板与轮盘都使用 macOS 面板窗口；原生显示确认与图片解码完成后才启动动画、音效和显示时长。选择 ID 去重，后续动作确认不会重播或打断同一次反馈。需要视野在框选结束后播放，避免把反馈录入截图；取消或权限失败仍反馈选择，并单独说明错误。图片加载失败仍会尝试播放音效，音效失败不停止动画；播放异常会在小窗短暂提示，最近 16 次素材名、位置和播放阶段记录在 `~/.dsh/quick-help/media-status.json`，不包含对话文本或凭据。

设置页每 1.5 秒更新助手、权限和模型状态，只读取机器状态，不恢复会话或改变轮盘目标。状态刷新保留尚未保存的快捷键，失败时保留上次结果并显示重试提示；关闭页面会取消请求和后续刷新。
